# TASK-000 — Repository Audit

## Goal

Inspect the live repository and produce a short implementation map before changing architecture.

## Read first

- `02_CURRENT_REPOSITORY_BASELINE.md`
- `32_CODEX_EXECUTION_PROTOCOL.md`

## Required work

1. Identify current packages, contracts, settings, tests, and composition root.
2. Locate any existing knowledge, EDA, KiCad, parser, or exporter code before creating new concepts.
3. Record current Python/dependency versions and test command.
4. Map dossier concepts to existing equivalents and note naming conflicts.
5. Do not change behavior unless a tiny documentation-only adjustment is required to record the audit.

## Tests

- Run the existing test suite or the repository-standard baseline command.

## Definition of done

- Produce an audit summary with proposed file mapping.
- Existing baseline test result is recorded.

## Non-goals

- No implementation of knowledge or KiCad features.
