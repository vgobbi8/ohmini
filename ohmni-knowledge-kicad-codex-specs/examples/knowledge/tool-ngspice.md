# ngspice Tool Knowledge

## Capabilities

- parse supported SPICE netlists;
- run operating-point analyses;
- run transient analyses;
- run AC analyses;
- report parser/simulation errors.

## Limitations

A successful ngspice execution does not by itself prove that the circuit satisfies the user's functional intent, component ratings, safety requirements, or KiCad ERC/PCB DRC constraints.
