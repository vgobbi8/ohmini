# 12 — Initial Electronics Knowledge Fixtures

Add a tiny curated fixture set solely to prove the representation and provider.

Do not attempt to build the full Ohmni electronics corpus in this task.

Suggested fixtures:

1. **RC low-pass entity/concept**
2. **RC cutoff formula**
3. **RC low-pass design procedure**
4. **SPICE reference-node constraint**
5. **ngspice tool capability**
6. **Example KiCad symbol entity** used only in fixture tests

## Fixture quality rules

- every knowledge item must have stable ID;
- every manually authored item must retain a source reference;
- formulas must document variable meaning and applicability;
- procedures must contain ordered steps;
- tool capability must explicitly state limitations;
- examples must be clearly marked as examples, not authoritative manufacturer data.
